# Smart print — друк з Android на Canon MF3010 (sportik)

Принтер Canon MF3010 підключений по USB до ПК **DESKTOP-DUMAC87** (192.168.0.88), і ПК роздає його
по LPD (`lpd://192.168.0.88/MF3010`). Мак друкує туди через драйвер Canon. Драйвер перетворює
сторінку на закритий формат **UFR II LT** і шле його по LPD «як є». Android цього формату не вміє,
а LPD-служба Windows без перетворення пропускає лише простий текст. Тому зроблено інакше:

```
Android (будь-який застосунок → «Друк» / «Поділитися»)
   │  HTTP, порт 8631: PDF / JPEG / PNG / текст
   ▼
SportikPrint на DESKTOP-DUMAC87  ──  драйвер Canon у Windows  ──USB──▶  MF3010
```

Мак для цього не потрібен. LPD-доступ, яким друкує Мак, лишається як був.

## Що де

| Тека | Що це |
|---|---|
| `windows/` | служба для ПК з принтером (.NET 10, один exe без встановлення .NET) |
| `android/` | застосунок «Smart print» (Kotlin, без бібліотек, minSdk 26 = Android 8+) |
| `dist/` | готові файли: `SportikPrint-windows.zip` і `smart-print.apk` |

## 1. Windows-ПК (один раз)

1. Скопіювати `dist/SportikPrint-windows.zip` на DESKTOP-DUMAC87 і розпакувати.
2. Двічі клацнути `install.cmd` і погодитися на права адміністратора. Скрипт:
   - кладе програму в `C:\Program Files\SportikPrint`;
   - ставить службу Windows **SportikPrint**: автозапуск з ПК і перезапуск після збою;
   - відкриває в брандмауері порт 8631, лише для локальної мережі;
   - друкує, який принтер знайдено, і адреси ПК для телефону.
3. Принтер вибирається сам: перший, у назві якого є «MF3010». Інший принтер можна вказати
   в `C:\Program Files\SportikPrint\appsettings.json` (`"Printer": "точна назва"`), після чого
   перезапустити службу SportikPrint.

Якщо зі служби друк не йде (завдання «OK», а папір не виходить), служба Windows (LocalSystem)
може не мати доступу до драйвера. Тоді запустіть `install.cmd -AsUser`. Програма стартуватиме при
вході користувача, тож ПК має бути залогінений.

Видалити: `install.cmd -Uninstall`.
Журнал завдань: `C:\ProgramData\SportikPrint\print.log`.
Перевірити з браузера будь-якого пристрою в мережі: `http://192.168.0.88:8631/api/status`.

**IP ПК.** Якщо адреса 192.168.0.88 видається роутером по DHCP, вона може змінитися. Тоді треба
закріпити її за ПК у роутері (DHCP reservation) або вписати нову адресу в застосунку.

## 2. Телефон

1. Встановити `dist/smart-print.apk` і дозволити встановлення з цього джерела.
2. Відкрити «Smart print». За замовчуванням адреса `192.168.0.88:8631`. Має з'явитися
   «✓ Готовий» і назва принтера у Windows.
3. Друкувати:
   - **меню «Друк»** у будь-якому застосунку (Chrome, Галерея, Gmail, Диск, PDF-переглядач)
     → принтер **Canon MF3010 · Smart print** (не «… @ MacBook» — то друк через Мак). Android сам перетворює документ на PDF A4, а копії
     й формат вибираються там же. При першому друці Android один раз питає «Use Smart print?», треба натиснути OK;
   - **«Поділитися» → «Друк на sportik»**: PDF, фото (і кілька одразу) або текст;
   - кнопка **«Вибрати файл і надрукувати»** в самому застосунку.

Якщо принтера нема в меню «Друк»: «Налаштування друку Android» → увімкнути службу «Smart print»
(на Samsung: Налаштування → Підключення → Інші налаштування → Друк).

## Як друкується

- **PDF.** Сторінки рендеряться в Windows (`Windows.Data.Pdf`, 300 dpi, налаштовується `RenderDpi`)
  і йдуть у драйвер. A4 на A4 друкується 1:1. Альбомні сторінки повертаються самі. Більший формат
  зменшується, а з галочкою «вписати в аркуш» вписується в поле друку.
- **Фото.** Враховується поворот з EXIF телефона, фото вписується в аркуш, альбомне друкується
  альбомно. Багатосторінковий TIFF теж друкується.
- **Текст.** UTF-8 або cp1251, Consolas 10, поля з драйвера.
- Копії розбираються самою службою (1,2,3,1,2,3), тож від драйвера це не залежить.
- Завдання йдуть по черзі. Телефон отримує відповідь, коли документ уже в черзі Windows.
- Стан у діалозі друку («Немає паперу», «Offline», кількість завдань у черзі) береться з WMI
  Windows. Для USB-принтерів він буває неточним, тому друк при ньому не блокується.

## Протокол (якщо знадобиться ще клієнт)

```
GET  /api/status
     → {"ok":true,"printer":"Canon MF3010","ready":true,"state":"Готовий","queuedJobs":0,"machine":"DESKTOP-DUMAC87",...}
POST /api/print?copies=1&title=Назва&media=ISO_A4&fit=0     тіло = сам файл
     → {"ok":true,"pages":3,"printer":"Canon MF3010"}   або   {"ok":false,"error":"..."}
```

Формат визначається за вмістом (`%PDF`, JPEG, PNG, GIF, BMP, TIFF, інакше текст), Content-Type
лише підказка. Якщо в `appsettings.json` заданий `Token`, його треба передавати заголовком
`X-Print-Token` (у застосунку це поле «Ключ»).

## Збірка

```bash
# Windows-служба (збирається й на Mac)
cd windows && dotnet publish -c Release -o ../dist/SportikPrint

# перевірка без Windows: на Mac/Linux служба не друкує, а складає файли в received/
cd windows && dotnet run -p:RuntimeIdentifier=osx-arm64 -p:SelfContained=false

# Android (JDK 21, Android SDK 37)
cd android && ./gradlew assembleRelease     # app/build/outputs/apk/release/app-release.apk
```

Реліз підписується debug-ключем, якщо в `~/.gradle/gradle.properties` не задано `print.storeFile`
та інші `print.*`. Для встановлення APK-файлом цього досить. Оновлення ставиться поверх лише тим
самим ключем.

Перевірено на емуляторі Android 16 проти служби в режимі dry run: «Поділитися», вибір файлу,
системне меню «Друк» з Chrome, стан «ПК недоступний». Сам друк через Windows-драйвер на
DESKTOP-DUMAC87 ще не перевірявся.
